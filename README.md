# Iolanda Rizzo — Lash & Brow Artist

Landing page frontend mobile-first per Iolanda Rizzo.

## Struttura
- `index.html` — struttura completa della landing
- `styles.css` — UI, responsive design, animazioni e placeholder
- `script.js` — menu mobile, reveal on scroll, micro-interazioni e parallax

## Come usarla
Apri `index.html` direttamente nel browser oppure servila con un qualsiasi web server statico.

## Dove inserire i contenuti reali
Cerca in `index.html`:
- `INSERISCI QUI LA FOTO HERO`
- `FOTO IOLANDA`
- `FOTO LAVORO ...`
- `INSERISCI SCREEN WHATSAPP`
- `INSERISCI_EMAIL@QUI.IT`

Per le immagini, sostituisci i `div.placeholder-image` con `<img>` mantenendo le rispettive classi, oppure modifica direttamente il CSS.

## Email
Nel bottone contatti sostituisci:
`mailto:INSERISCI_EMAIL@QUI.IT`
con l'indirizzo reale.

## Nota
Le font vengono caricate da Google Fonts. Se il sito dovrà funzionare completamente offline, scarica le font e servile localmente.
